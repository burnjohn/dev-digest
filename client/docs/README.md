# client/docs

Design notes and deeper explanations for `@devdigest/web` that are **too long for
[AGENTS.md](../AGENTS.md)** — component architecture, data-flow write-ups, i18n/theming
decisions, accessibility notes.

Rule of thumb: a *map* (where things live, a command, a one-line convention) belongs in
AGENTS.md; an *explanation* read only when a task needs it belongs here and gets linked.
