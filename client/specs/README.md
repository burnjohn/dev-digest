# client/specs/

UI feature specifications for `@devdigest/web`.

## Conventions

- One file per UI feature
- Filename: `<feature>.md` (e.g., `cost-badge.md`, `severity-filter.md`)
- Format: what it shows · where it appears · supported values · empty/loading/error states
- Specs describe *what* the user sees and expects — not component structure or implementation
