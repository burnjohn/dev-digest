# server/specs/

Behavioral specifications for `@devdigest/api` services and endpoints.

## Conventions

- One file per feature or service boundary
- Filename: `<feature>.md` (e.g., `review-run.md`, `repo-index.md`)
- Format: inputs → expected behavior → outputs → edge cases
- Specs describe *what* the system does, not *how* — implementation details go in `docs/`
