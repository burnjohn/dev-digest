# server/docs/

Architecture decisions and design documentation for `@devdigest/api`.

## Conventions

- One file per decision or subsystem
- Filename: `<topic>.md` (e.g., `di-container.md`, `sse-streaming.md`, `secrets-flow.md`)
- Link from `server/CLAUDE.md` when a decision directly affects daily development
- Link from `server/insights.md` when a doc explains the *why* behind a discovered gotcha
