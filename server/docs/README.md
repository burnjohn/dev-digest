# server/docs

Design notes and deeper explanations for `@devdigest/api` that are **too long or too
detailed for [AGENTS.md](../AGENTS.md)** — architecture write-ups, adapter/DI rationale,
migration notes, per-module design docs.

Rule of thumb: if it's a *map* ("where things live", a command, a one-line gotcha) it
belongs in AGENTS.md; if it's an *explanation* Claude should read only when a task needs
it, it belongs here and gets linked from AGENTS.md.
